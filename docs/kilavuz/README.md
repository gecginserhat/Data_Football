# Kurgu kullanıcı kılavuzu

Kurgu, kulübünüzün duran top hazırlığını tek yerde toplar: veri ve rakip analizi, öneriler, haftalık plan, rutin kütüphanesi, maç içi kayıt, video ve raporlar. Bu kılavuz rollere göre bölümlere ayrılmıştır; kendi rolünüzle başlayın.

| Bölüm | Kimin için |
|---|---|
| [1. Başlarken](01-baslarken.md) | Herkes |
| [2. Analiz ve maç hazırlığı](02-analiz-ve-hazirlik.md) | Duran top antrenörü, analist, teknik direktör |
| [3. Rutinler](03-rutinler.md) | Duran top antrenörü, analist |
| [4. Maç günü: canlı kayıt ve video](04-mac-gunu.md) | Analist, duran top antrenörü |
| [5. Raporlar ve brifing](05-raporlar.md) | Antrenörler, analist |
| [6. Performans, kadro ve markaj](06-performans-ve-kadro.md) | Performans ve sağlık ekibi, duran top antrenörü |
| [7. Oyuncular](07-oyuncular.md) | Oyuncular |
| [8. Yönetim](08-yonetim.md) | Kulüp yöneticisi |
| [Sözlük ve sık sorular](09-sozluk-sss.md) | Herkes |

Ekran görüntüleri tablet görünümündendir ve "Örnek veri" rozetli demo kaydını gösterir. Teknik ekip için kurulum ve işletim belgeleri `docs/runbooks/` altındadır.
